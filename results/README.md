# Checked-in Benchmark Artifacts

`local_qwen7b_10p/real_candidates.csv` contains the raw final candidate records from the local Qwen2.5-7B-Instruct benchmark. The `analysis/` directory contains tables regenerated from those records.

These artifacts support verification of the reported offline automatic-evaluation results. They are not human ratings, platform logs, click-through-rate observations, or conversion measurements.
