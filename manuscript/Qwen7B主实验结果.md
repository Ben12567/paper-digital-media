# Qwen7B 主实验结果

## 实验设置

- 主模型：`Qwen2.5-7B-Instruct`
- 推理环境：`transformers + RTX 3090`
- 图像生成：关闭，仅保留 `visual_prompt`
- 任务规模：`5` 个产品 `x 4` 类受众，共 `20` 个广告任务
- 方法数量：`5` 个主方法 + `4` 个消融方法
- 最终广告样本：`180` 条

## 主实验结果

在五个主方法中，`Ours_EAI_CO` 的平均 `reward = 0.8450`，高于所有主基线：

- `B1_SingleShot_API = 0.8143`
- `B2_OpenSource_Only = 0.8117`
- `B3_PromptEngineered_AI = 0.8010`
- `B0_Template = 0.7106`

在 `predicted engagement` 上，`Ours_EAI_CO = 0.8144`，同样高于所有主基线方法。

## 显著性结果

相对 `Ours_EAI_CO`：

- 对 `B0_Template`，reward 提升 `+0.1344`，`p = 9.54e-07`
- 对 `B1_SingleShot_API`，reward 提升 `+0.0307`，`p = 0.00962`
- 对 `B2_OpenSource_Only`，reward 提升 `+0.0333`，`p = 0.00243`
- 对 `B3_PromptEngineered_AI`，reward 提升 `+0.0440`，`p = 0.00415`

这说明在 `Qwen2.5-7B-Instruct` 上，探索式优化框架相对于模板法和单轮生成基线具有稳定优势。

## 受众分层结果

`Ours_EAI_CO` 在四类受众上的平均 reward 为：

- `students = 0.8502`
- `young_professionals = 0.8198`
- `family_users = 0.8275`
- `price_sensitive_consumers = 0.8826`

该结果表明，方法优势并不限于单一受众，其中在价格敏感型消费者和学生场景中的表现更突出。

## 消融实验

消融结果中有两点成立，一点需要重新解释。

### 成立的结论

- 去掉多样性约束：`0.8450 -> 0.7266`
- 去掉迭代优化：`0.8450 -> 0.8279`

这支持“多样性保持”和“迭代 refinement”对创意优化有效。

### 需要谨慎解释的结论

- `w/o factual penalty = 0.8648`，高于 `Ours_EAI_CO`
- `w/o audience modeling = 0.8487`，略高于 `Ours_EAI_CO`

这说明当前自动 reward 设计下，事实惩罚项和受众建模项没有完全按照预期转化为更高总 reward。更准确地说，`Ours_EAI_CO` 仍然是主方法中最优，但“所有消融都应低于完整方法”的机制性论证目前还不够完全。

因此，在正式投稿版中，这部分不能简单写成“所有模块均被严格验证”。更严谨的写法应为：

1. 多样性约束和迭代优化的贡献明确成立；
2. 受众建模在部分细分指标上有价值，但在当前 reward 聚合下仍需进一步校准；
3. 事实惩罚项更多体现为约束与安全性设计，而非纯粹的 reward 最大化项。

## 成本分析

`Ours_EAI_CO` 平均每任务模型调用数为 `8.0`，平均延迟约 `20195.45 ms`，中位延迟约 `18672.00 ms`。相较于单轮生成方法，探索式方法的计算成本更高，但在单卡 `RTX 3090` 上仍可稳定运行。

需要注意的是：

- `w/o audience modeling` 的平均延迟异常偏高，主要由单个长尾任务拉高；
- 其中位延迟 `22537.50 ms` 更能反映其常规推理成本；
- 因此成本分析应同时报告平均值与中位数。

## 当前论文论证力度判断

这组 `Qwen7B` 结果足以支撑以下论点：

1. 探索式优化方法显著优于模板和单轮基线；
2. 多样性约束与迭代优化是关键有效模块；
3. 本地可复现开源模型上可以稳定获得主结论。

但它还不足以完全支撑以下更强表述：

1. 完整框架内部每个模块都被充分、单调地验证；
2. 受众建模和事实惩罚在当前 reward 定义下必然提升总体表现；
3. 该结论已经完成跨模型泛化验证。

因此，如果目标是“能写成论文正文”，当前结果已经够；如果目标是“最稳投稿版”，仍建议补：

- `gpt-5.4-mini` 的 cross-model validation 子集实验；
- 更大规模的 `Qwen7B` 主实验，至少扩展到 `10` 个产品；
- 对 reward 权重和惩罚项做一次重新校准。
