# 本地 GPU 正式实验结果

## 实验设置

- 本地文本生成模型：`Qwen2.5-1.5B-Instruct`
- 推理环境：`transformers + RTX 3090`
- 图像生成：关闭，仅保留 `visual_prompt`
- 任务规模：`5` 个产品 `x 4` 类受众，共 `20` 个广告任务
- 方法数量：`5` 个主方法 + `4` 个消融方法
- 最终广告样本：`180` 条

## 主实验结果

主实验中，`Ours_EAI_CO` 取得最高平均 reward，为 `0.8302`。相比之下：

- `B1_SingleShot_API = 0.7979`
- `B2_OpenSource_Only = 0.7827`
- `B3_PromptEngineered_AI = 0.7888`
- `B0_Template = 0.7106`

在 `predicted engagement` 指标上，`Ours_EAI_CO = 0.8007`，同样高于所有主基线方法。

## 显著性结果

相对于 `Ours_EAI_CO`：

- 对 `B0_Template`，reward 提升 `+0.1196`，`p = 9.54e-07`
- 对 `B1_SingleShot_API`，reward 提升 `+0.0323`，`p = 0.01198`
- 对 `B2_OpenSource_Only`，reward 提升 `+0.0475`，`p = 0.00243`
- 对 `B3_PromptEngineered_AI`，reward 提升 `+0.0415`，`p = 0.01074`

这说明在当前本地真实生成实验中，探索式优化框架相对于单轮生成和模板方法具有稳定优势。

## 受众分层结果

`Ours_EAI_CO` 在四类受众上的平均 reward 分别为：

- `students = 0.8672`
- `young_professionals = 0.8342`
- `family_users = 0.8170`
- `price_sensitive_consumers = 0.8025`

其中，学生群体上的提升最明显，说明探索式生成在强调便携、效率、预算友好的广告任务中更容易获得稳定高分创意。

## 消融实验

消融结果表明：

- 去掉多样性约束：`0.8302 -> 0.7157`
- 去掉事实惩罚：`0.8302 -> 0.8228`
- 去掉迭代优化：`0.8302 -> 0.8074`
- 去掉受众建模：`0.8302 -> 0.8009`

其中，多样性约束和受众建模对最终表现影响最大。尤其是在 `w/o audience modeling` 设置下，`audience_fit` 从 `0.5450` 下降到 `0.4312`，说明受众条件建模确实为目标化广告创意提供了实质贡献。

## 成本分析

`Ours_EAI_CO` 平均每任务模型调用数为 `8.0`，平均延迟约 `27090.20 ms`，中位延迟约 `24750.50 ms`。相比单轮生成方法，探索式优化的计算成本更高，但仍在单卡本地 GPU 可承受范围内。

需要注意的是，`B3_PromptEngineered_AI` 在本地推理中出现了单个长尾任务，导致平均延迟被异常值明显拉高。因此本研究在成本分析中同时报告平均值与中位数，以避免单个异常样本误导总体判断。

## 补充说明

本轮实验完成了本地真实文本生成、全量自动评估、分层结果、显著性检验与消融分析。基于本地 `1.5B` 小模型的 judge 代理实验表现出明显不稳定性，因此当前投稿版更适合将 judge 结果作为补充分析，而将正式结论建立在全量自动评估和机制性消融之上。
