# Manuscript Working Draft

`applsci_mdpi_template_exact.tex` is the retained English manuscript working draft. The `Definitions/` directory is extracted from the official MDPI article template and is required for compilation.

Use Overleaf or a local TeX Live installation with pdfLaTeX. The bundled Tectonic compiler is not compatible with the official MDPI `pdftex` class path used by this draft.

Before external circulation or submission, replace all author, affiliation, ORCID, correspondence, and date placeholders with verified metadata. The manuscript currently reports only the checked-in local Qwen2.5-7B-Instruct benchmark. Add commercial-model evidence only after rerunning it with the same task protocol and reward weights.
